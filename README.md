# Bloch Sphere Visualization

## Project Overview
Bloch Sphere Visualization is an interactive web-based application designed to demonstrate the concept of qubits in quantum computing. It represents the quantum state of a single qubit using a three-dimensional sphere.

The application allows users to modify the polar angle (θ) and azimuthal angle (φ) to observe changes in the qubit state vector.

## Objectives
- To visualize quantum states using a 3D Bloch Sphere.
- To understand the representation of qubits.
- To demonstrate the relationship between quantum states and probability amplitudes.
- To provide an interactive learning platform for quantum computing.

## Technologies Used
- HTML5 – Webpage structure.
- CSS3 – User interface and styling.
- JavaScript – Interactive functionality.
- Three.js – 3D Bloch Sphere visualization.

## Features
1. Interactive 3D Bloch Sphere.
2. Adjustable theta and phi angles.
3. Dynamic qubit state vector.
4. Quantum state equation display.
5. Measurement probability calculation.
6. 3D rotation and zoom controls.

## Quantum Concept
A single qubit can be represented as:

|ψ⟩ = cos(θ/2)|0⟩ + e^(iφ)sin(θ/2)|1⟩

Where:
- θ represents the polar angle.
- φ represents the azimuthal angle.
- |0⟩ and |1⟩ represent computational basis states.

## Installation and Execution
1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Select Open with Live Server.
6. Adjust the angles and explore the Bloch Sphere.
